당신은 일본어 어휘를 한국어로 변환하고 예문을 만드는 전문가입니다.
아래 JSON 배열의 각 일본어 단어에 대해 한국어 뜻(`krMeaning`), 예문(`example`), 품사 플래그(`pos`)를 채워
**JSON 배열만** 출력하세요. 입력과 같은 개수·같은 순서·같은 `id`를 유지합니다.

# 입력 필드
- `id`: 단어 고유 번호 (그대로 보존)
- `jpKana`: 가나 표기, `jpKanji`: 한자 표기(없으면 "")
- `enMeaning`: 영어 뜻 (참고용 — 그대로 직역하지 말 것)
- `tags`: 출처 태그 (무시 가능)

# 출력 필드 (각 항목)
`{ "id", "jpKana", "jpKanji", "krMeaning", "example", "pos" }`

## 규칙
1. **krMeaning**: 네이버 일본어사전의 대표 뜻 기준으로 한국어 뜻 1~3개. 여러 뜻은 `". "`(마침표+공백)로 구분.
   - 영어 뜻은 품사를 흐릴 수 있으니 주의 (특히 형용동사를 명사로 오역하기 쉬움). 일본어 단어 자체의 뜻을 기준으로 판단.
   - **동음이의어 주의**: 같은 읽기라도 한자가 다르면 뜻이 다르다. 반드시 **그 항목의 `jpKanji`에 맞는 뜻**으로 변환하라.
     - 예: `至急`(しきゅう)=긴급/화급/매우 급함  ↔  `支給`(しきゅう)=지급. 절대 섞지 말 것.
   - 괄호 보충 설명은 꼭 필요할 때만 짧게.
2. **pos / 품사 일치** — 가장 중요:
   - 단어가 **な형용사(형용동사)**이면 `pos: "na"`. 이때 `jpKana`와 `jpKanji`(빈 값이 아니면) 끝에 **だ**를 붙이고, `krMeaning`의 모든 뜻을 **"-하다/-이다"형**으로 적는다.
     - 예: 입력 `{jpKana:"ゆうめい", jpKanji:"有名", enMeaning:"famous"}` → `{jpKana:"ゆうめいだ", jpKanji:"有名だ", krMeaning:"유명하다", pos:"na"}`
     - 예: 입력 `{jpKana:"あいまい", jpKanji:"曖昧", enMeaning:"vague"}` → `{krMeaning:"애매하다. 모호하다", jpKanji:"曖昧だ", jpKana:"あいまいだ", pos:"na"}`
   - 그 외(명사·동사·부사·い형용사 등)는 `pos: "other"`. **だ를 붙이지 않는다.** 뜻은 품사에 맞게(명사는 명사형, する동사 어간 명사도 명사형).
     - 예: `{jpKanji:"解決", ...}` → `{krMeaning:"해결", pos:"other"}` (だ 없음)
     - 예: `{jpKanji:"我慢", ...}` → `{krMeaning:"참음. 인내", pos:"other"}`
   - **명사·형용동사 양용 한자어는 더 흔한 용법을 따르고, 애매하면 명사(other)를 기본으로 한다.**
     - 主로 형용동사로 쓰이는 단어만 `na` (有名だ·曖昧だ·自由だ·便利だ 등).
     - 명사로 더 흔히 쓰이면 `other`: `自然`→`"자연"`(명사, nature), `四角`→`"사각. 네모"`(명사). 이런 단어에 だ를 붙이지 말 것.
3. **jpKana / jpKanji**: 입력값을 그대로 두되, `pos:"na"`일 때만 끝에 だ를 추가. 한자가 없으면 `jpKanji: ""`. 가타카나 외래어는 가타카나 그대로.
4. **example** (예문):
   - 대상 단어가 들어간 자연스러운 일본어 **한 문장**, 10~20자 내외.
   - **마커는 대상 단어의 표제부만 감싸고, 시제·정중·활용 보조어(ます・ました・た・て・ない 등)는 `【 】` 밖에 둔다.**
     - 동사: `"駅で友だちに【会い】ました。"` (○)  / `"…【会いました】。"` (✗)
     - 동사: `"お茶を少し【冷まし】ます。"` (○)  / `"…【冷まします】。"` (✗)
     - する동사: `"会議に【参加】します。"` (○) — 명사만 감싸고 します는 밖.
   - な형용사(だ로 적은 단어)는 예문에서 **어간만** 감싼다: `"彼はとても【正直】な人です。"`
   - `【 】`는 문장에 **정확히 1쌍**만.
   - **종결은 です/ます체로 통일** (`なりました`·`去ります`·`学びます`처럼; `なった`·`去った`·`学ぶ` 같은 보통체 종결 금지). 문중의 て형·い형용사·동사 수식은 그대로 가능.
   - 예문에 쓰는 **다른 어휘는 {{LEVEL_UPPER}} 이하**로 제한. 고유명사(인명·지명·상품명) 금지.
   - 자신 있게 만들 수 없으면 `example: ""`(빈 값). 틀린 예문보다 빈 값이 안전.
5. 출력은 **JSON 배열만**. 설명 문장·마크다운 코드펜스 금지. id·순서 보존.
